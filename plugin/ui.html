Rebuild the asset index

Run the plugin inside the library file and press the button — it collects every component, its key and a preview. Metadata and previews are stored as separate files so the plugin opens instantly.

  1. Publish the library (Assets → Library → Publish) if anything changed
  2. Press “Build index”
  3. Download asseter-bundle.json — one file instead of all
  4. In the terminal: ./publish-index.sh --pull <gist_id>
